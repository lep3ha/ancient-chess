# Chess

Шахматы на C++ и SFML. Автор — Sasha Youguy.

Школьный проект (2019), изначально написанный для Windows в Visual Studio. Игровая логика
сохранена: при упорядочивании репозитория правила ходов, обработка ввода и отрисовка
не перерабатывались.

## Структура

```text
src/
├── main.cpp              Точка входа
├── board/                Доска и клетки: Board, Cell
├── pieces/               Фигуры: Figure, Pawn
├── moves/                Описание хода: Move
├── game/                 Игровой цикл: Game.hpp
└── common/               Общие типы и константы: Definitions.hpp
assets/
├── images/               Доска, фигуры и иконка окна
└── fonts/                Шрифты Nanum Gothic
CMakeLists.txt            Сборка проекта
```

## Требования

- CMake 3.21 или новее.
- Компилятор с поддержкой C++14.
- SFML **2.5 или 2.6** с модулями graphics, window и system. SFML 3 не подходит.

SFML устанавливается отдельно; готовые библиотеки и кеши зависимостей в репозитории
не хранятся. Для Windows сборка SFML должна соответствовать компилятору и разрядности
приложения.

## Сборка в Windows

Из терминала разработчика Visual Studio, с установленными средствами разработки C++:

```powershell
cmake -S . -B build -A x64 -DSFML_DIR="C:/Libraries/SFML/lib/cmake/SFML"
cmake --build build --config Release
cd build/Release
.\chess.exe
```

Замените путь к SFML на свой. Для 32-битной библиотеки используйте `-A Win32`
в отдельной папке сборки. CMake копирует ресурсы и DLL модулей SFML рядом
с исполняемым файлом. Для Debug используйте `--config Debug` и папку `build/Debug`.

Можно также открыть корневую папку в Visual Studio с поддержкой CMake. Рабочая
папка отладчика для сгенерированного решения настроена на каталог исполняемого файла.

## Сборка в macOS и Linux

При установленной SFML 2:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
cd build
./chess
```

Если CMake не находит библиотеку, добавьте при настройке
`-DSFML_DIR=/путь/к/SFML/lib/cmake/SFML`.
Например, для Homebrew `sfml@2`:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_PREFIX_PATH="$(brew --prefix sfml@2)"
```

Запускайте игру из папки исполняемого файла: относительные пути `assets/...`
отсчитываются от текущей рабочей папки. Сборка обновляет копию ресурсов автоматически.
При переносе игры скопируйте и папку `assets`.

## Управление

Выберите фигуру левой кнопкой мыши, затем нажмите на клетку назначения.
Возможные ходы отмечаются на доске, запись ходов выводится в консоль.

## Оформление кода

Исходники используют UTF-8, четыре пробела и стиль из `.clang-format`:

```sh
find src -type f \( -name '*.cpp' -o -name '*.hpp' \) -exec clang-format -i {} +
```

Каталоги сборки, кеш Visual Studio и бинарные файлы исключены через `.gitignore`.
Старые `.sln` и `.vcxproj` заменены CMake; при необходимости решение Visual Studio
генерируется командой настройки сборки.

Помимо форматирования и новых путей к ресурсам сделаны два исправления для сборки:
убран лишний символ после `#include` в `Board.cpp`, а временный `Cell`, адрес которого
сохранялся в `selectedCell`, заменён локальным объектом с временем жизни до конца
`gamePlay()`. Алгоритмы игры не менялись.
